# CS-350-12726-M01-Emerging-Sys-Arch-Tech
Summarize the project and what problem it was solving.
The project was to create a basic thermostat device from a Raspberry Pi and a breadboard. This project was to aid in our understanding of embedded systems. It taught making the basic circuitry for the device, coding it in Python and recording results. 
What did you do particularly well?
I think I did the circuit and the coding well. I was able to use experience with this type of project to aid in creating both functional circuits and code. With my experience, the provided templates and test code, I was able to puzzle through what code was needed to make each part function. 
Where could you improve?
I could improve my attention to spacing. One step required the lights to blink in a particular way and mine did not quite do it because of spacing on the lines. This determines which part of the code these lines function inside of. It is important to get this correct, so the code runs correctly. 
What tools and/or resources are you adding to your support network?
I am adding more experience using breadboards, Raspberry Pi, and Python. I have used each before but not together in such a way, I have not created circuits for embedded systems before.
What skills from this project will be particularly transferable to other projects and/or course work?
The skills in basic coding will be useful in any projects, course work or jobs. I learned more about using Python which I use for different projects, such as robots. I also understand embedded systems more, which would be useful to lots of projects and more. 
How did you make this project maintainable, readable, and adaptable?
This project uses functions to make it easy to adapt to other uses. There is documentation throughout the code to provide guidance for maintaining and reading it. This would help another developer understand what parts do what so they can reuse the parts they find useful for their version of the project.
